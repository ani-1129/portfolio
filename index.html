Deployment Guide

Go Live — Deploy
Your Portfolio

🐙 GitHub Pages (Free)

1
Create a GitHub Repository
Go to github.com → New Repository → Name it portfolio or ani-1129.github.io → Set to Public → Create.
2
Upload Your File
Rename this file to index.html. Then open your terminal and run:
# In the folder containing index.html
git init
git add .
git commit -m "Initial Portfolio"
git branch -M main
git remote add origin https://github.com/ani-1129/portfolio.git
git push -u origin main
3
Enable GitHub Pages
Go to repository → Settings → Pages → Source: main branch → Save. Wait 2 minutes.
4
Your Live URL
https://ani-1129.github.io/portfolio

🚀 Netlify (Recommended — Fastest)

1
Sign Up at Netlify
Go to netlify.com → Sign up with your GitHub account (free).
2
Drag & Drop Deploy
Go to Netlify Dashboard → Sites → Drag and drop the folder containing your index.html directly. Done in 10 seconds!
3
Or Deploy via GitHub
Add new site → Import from GitHub → Select your repo → Branch: main → Deploy site.
4
Your Live URL + Custom Domain
https://aniket-portfolio.netlify.app
To add www.aniketsingh.dev: Site Settings → Domain Management → Add custom domain → Buy domain on GoDaddy/Namecheap → Point DNS to Netlify's servers (CNAME: aniket-portfolio.netlify.app).

⚡ Vercel (Professional)

1
Sign Up at Vercel
Go to vercel.com → Sign up with GitHub (free).
2
Import GitHub Repository
New Project → Import your portfolio repo → Framework: Other → Deploy. Auto-deploys on every git push!
3
Your Live URL
https://aniketsingh.vercel.app
4
Add to Your Resume
Copy the live URL and paste it in your resume under Portfolio section. Every recruiter can now visit your live site!
